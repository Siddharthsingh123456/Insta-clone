# Instagram-Inspired Social UI Clone

A static frontend learning project that recreates selected social-media interface patterns using HTML, CSS, and JavaScript.

## Project contents
- `index.html` — repository entry page
- `Insta Clone/index.html` — project interface
- `Insta Clone/style.css` — page styling
- `Insta Clone/script.js` — client-side interactions

## Technology
HTML5 · CSS3 · JavaScript

## Run locally
```bash
git clone https://github.com/Siddharthsingh123456/Insta-clone.git
cd Insta-clone
```
Open `index.html` in a browser or open `Insta Clone/index.html` for the nested project page.

No package installation or build step is required for this static frontend.

## Learning objectives
- Practice responsive frontend layouts
- Work with CSS styling and reusable visual patterns
- Add interactions with browser JavaScript
- Structure a small static website

## Scope and branding
This is an independent educational interface clone. It is not affiliated with or endorsed by Meta or Instagram and does not connect to Instagram accounts or services.
